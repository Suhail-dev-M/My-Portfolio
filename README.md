# Suhail — Developer Laboratory & 3D Portfolio

An interactive, 3D realistic notebook portfolio & developer laboratory showcasing skills, featured projects, learning roadmap, and cybersecurity laboratory setup.

## 🚀 Features

- **3D Interactive Notebook**: Smooth page-flipping physics with dynamic depth, spiral rings, and leather cover.
- **Developer Identity & Philosophy**: Overview of Computer Science track, DSA in C, and core strengths.
- **Filterable Technical & Cybersecurity Matrix**: Categorized skill chips across Programming (Python, Java, C/C++, JS/TS, PHP, SQL), Web (React, Tailwind), Android (Android Studio, Java, Flutter, Supabase), Cybersecurity (Kali Linux, Nmap, Metasploit, Nessus, Shodan), Networking, AI & ML (Qwen2.5-Coder, DeepSeek), Hardware & Electronics, and Cloud DBs.
- **Featured Laboratory Projects**:
  - `GlassMessaging`: Android / Supabase Messaging App
  - `Storage Recovery & Analysis Tool`: Python MBR & raw sector scanner
  - `Cybersecurity & Ethical Hacking Lab`: Kali Linux & VirtualBox setup
  - `Supabase Android Applications`: Complete CRUD & Auth integration
- **Explorations & Systems Lab**: ChatZonee, E-Commerce Site, Selenium Automation, AI Model Experiments, Electronics & Mini Li-ion UPS, Networking Lab, and PC Hardware Specs.
- **Interactive Developer CLI (`suhail@dev-lab:~$`)**: Terminal emulator supporting live interactive commands (`whoami`, `skills`, `projects`, `roadmap`, `contact`, `clear`).

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom 3D transforms & Glassmorphism), JavaScript (ES6+)
- **Typography**: Google Fonts (Caveat, Fira Code, Inter, Playfair Display, Special Elite)
- **Audio Assets**: Ambient audio generators & realistic page-flip sound effects
